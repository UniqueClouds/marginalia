## 数据文件与范围

[下载完整压缩 JSON（约 29.6 MB）](../data/nsf-awards-priority-2026-11-03.json.gz)。文件包含 19,630 条奖项记录、完整英文摘要、原数据中已有的中文摘要译文、PI/共同 PI、学校、金额、NSF 项目与部门、日期、主题标签、奖项链接，以及 NSF 记录列出的论文书目信息。34 条记录没有英文摘要；43 条记录已有中文摘要译文。

记录来自 2026-11-03 的本地筛选快照，沿用此前设定的学科范围、金额门槛及排除项；学生专门资助例外保留。页面中的“研究领域”是本项目整理的标签，不是 NSF 官方分类。论文条目是 NSF 记录提供的成果书目，列入页面不证明该奖项是论文的唯一资金来源。

NSF Award Search 说明，奖项数据及摘要文本属于公共领域；这份导出没有包含论文全文。[NSF Award Search 使用说明](https://www.nsf.gov/funding/award-search)
